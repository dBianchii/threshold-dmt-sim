# Threshold

First-person WebGL simulation of a DMT experience. Single file, no deps: open `index.html`.

- Flat: https://threshold-dmt-sim.vercel.app
- VR (WebXR, Quest / Pico / Vision Pro): https://threshold-dmt-sim.vercel.app/vr

`vr/index.html` is the same trip in stereo 3D with head tracking. Open it in the headset's browser and press Enter VR. Without a headset it runs as a drag-to-look 360 view.

Contains intense flashing imagery.
